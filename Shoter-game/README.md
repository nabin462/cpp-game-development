# C++ Shooter Game

## About
A 2D shooter game developed using C++ and raylib.

## Features
- Player movement
- Shooting bullets
- Enemy spawning and movement
- Collision detection
- Score system
- Sound effects

## Technologies
- C++
- raylib
- Visual Studio Code
- Git and GitHub

## Project Structure
- `src/` - Source code
- `assets/` - Images and sounds
- `builds/` - Compiled game files
- `main.cpp` - Main game entry point

## Status
In development.
